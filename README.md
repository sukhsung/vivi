# Vivi - Geophone ADC Controller




## MacOS:
1. Download `.dmg` file and copy `Vivi.app` into `/Applications` folder.
2. Run `xattr -cr /Applications/Vivi.app` in terminal to bypass codesigning
3. Run `Vivi.app`



## Build Instruction
To get started, `npm install` then `npm start`
To get tailwind going during development `npx @tailwindcss/cli -i ./src/renderer/css/input.css -o ./src/renderer/css/output.css --watch`
